## Assignments

### Assignment 1 — Student Marks Analyzer

A JavaScript program that analyses a student's marks using functions, arrays, loops, conditional statements, and string methods.

**Covered tasks**
- Calculate total marks and percentage
- Find the highest and lowest marks
- Count passed subjects
- Convert the student's name to uppercase and calculate its length
- Determine a performance category

[**View Assignment 1 source code**](./ASSIGN-1.js)

### Assignment 2 — String and Array Problem-Solving Toolkit

A collection of JavaScript functions for common string and array problems.

**Covered tasks**
1. Reverse a string
2. Check whether a string is a palindrome
3. Count vowels and consonants
4. Find the second-largest distinct number
5. Remove duplicate array elements without using `Set`
6. Calculate the sum of even numbers in an array
7. Find the frequency of an element
8. Check whether two strings are anagrams
9. Move all zeros to the end of an array

[**View Assignment 2 source code**](./ASSIGN-2.js)
